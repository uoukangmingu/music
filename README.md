코드 뮤직 제너레이터 DUAL MODE v4
====================================

실행 방법
1. ZIP 압축을 풉니다.
2. START_code_music_generator_dual_mode_v4.html을 Chrome 또는 Edge로 엽니다.
3. 상단의 '클래식 피아노 모드'를 누릅니다.
4. 작곡 성향, 악장 성격, 피아노 음색을 선택한 뒤 '생성·재생'을 누릅니다.

권장 시작 설정
- 작곡 성향: 말러 · 장대한 서사
- 악장 성격: 서정적 아다지오
- 피아노 음색: 따뜻한 콘서트 그랜드
- 템포: 52~60 BPM
- 음표·대위 밀도: 4
- 서사·절정 강도: 7
- 출력 음량: 72~82

v4 핵심 수정
- 음표 하나당 여러 오실레이터와 노이즈를 겹치던 구조 제거
- 음표당 단일 최적화 피아노 파형으로 CPU 부하 감소
- 모든 건반의 시작과 종료에 부드러운 엔벨로프 적용
- 정지 버튼 클릭 시 짧은 페이드아웃 적용
- 고역의 치찰음이 강했던 리버브 임펄스를 부드러운 룸 잔향으로 교체
- 저역 뭉침 방지 하이패스, 과출력 방지 컴프레서 적용
- 현재 화음과 선율을 연결해 무작위 불협화음 대폭 축소
- 주제, 응답, 발전, 심연, 절정, 회귀 구조 유지
- WAV 저장 시 너무 작거나 큰 음량을 안전하게 보정
- 따뜻한 콘서트 그랜드, 부드러운 펠트, 맑은 실내 그랜드 추가

동봉 파일
- START_code_music_generator_dual_mode_v4.html: 실행 파일
- piano_preview_mahler_v4.wav: 수정된 엔진으로 만든 약 38초 피아노 예시

소리가 작을 때
- 프로그램의 '출력 음량'을 82~90으로 올립니다.
- Windows 볼륨 믹서에서 Chrome/Edge가 음소거되지 않았는지 확인합니다.
- 블루투스 기기를 쓰는 경우 브라우저를 다시 열어 출력 장치를 갱신합니다.

주의
이 프로그램은 외부 피아노 샘플이나 라이브러리를 사용하지 않습니다.
브라우저의 Web Audio API만으로 음색과 곡을 실시간 합성합니다.
